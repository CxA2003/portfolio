# Portfolio visual direction

The November 2026 revision takes its visual direction from the Persona 5 X official website and the portfolio video supplied by Cesar: angled cutout lettering, red and black patterned surfaces, framed navigation, and dark project panels. The hero illustration is an AI-generated interpretation based on an existing portrait; it is decorative, while the original portrait is identified in the About section. Game characters and official artwork are not included.

The site remains a conventional, navigable document with anchors and readable project descriptions. Motion is limited to short interactive transitions and is disabled for reduced-motion preferences. The project cards use graphic illustrations, not screenshots of the projects.

Validation: production build and source lint passed; desktop and 390px mobile layouts and project navigation were inspected in a browser. Physical-device and screen-reader testing remain outstanding. The repository-wide lint has pre-existing errors in historical and configuration files.
